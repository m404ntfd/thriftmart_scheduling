THRIFT MART DISPATCH RELEASES

Repository: m404ntfd/thriftmart_scheduling
Update VERSION and RELEASE-NOTES.md, then push main. GitHub Actions tests on
Windows/Linux, builds the Remote Manager and unified installer, tests an actual
installed server, then publishes the installer and the legacy update asset.
Only public stable releases with a valid three-part version are installed.
The updater verifies the GitHub SHA-256 asset digest and backs up data/code.
A failed startup restores prior program files. Database migrations must remain
backward compatible. Restore is an offline operation using the installer utility.

Keep customer data, backup archives, settings, credentials and runtime/ out of Git.
Updater FILES remains the original seven-file allowlist for compatibility with
0.2. Therefore launcher/remote/restore/runtime changes require the full installer.
One installer offers Server, Remote Manager or Both. Customer data remains local.

If power fails during code installation, stop the server and restore program
files from data/update-backups/<timestamp>. Restore data separately if needed.
External OneDrive backup archives include only data/settings, not installed code.
Reinstall the program before disaster recovery. OneDrive sync status is not
verified by the app; confirm the file is available in OneDrive independently.
