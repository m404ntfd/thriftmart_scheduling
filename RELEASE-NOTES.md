# Thrift Mart Dispatch 0.15.4

Request review opens with a Photos section before the appointment fields. Thumbnails open a larger in-app preview; closing the preview returns to the same review form. Attached photos are also shown first when editing approved appointments.

Pending totals now come from server-wide counts, so they do not depend on which requests the employee can review. Date ranges still use requested date and exclude cancellations. Opening review no longer adds the request to the appointment list.
