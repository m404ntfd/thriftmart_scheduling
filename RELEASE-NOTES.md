# Thrift Mart Dispatch 0.11.0

Employees can use an 8–256 character password or exactly four ASCII digits as a passcode, including leading zeros. My password / passcode at the bottom lets signed-in users change their own login after verifying their current credential. Administrator account creation/reset and Remote Manager accept both formats. Credentials remain salted/hashed; login rate limits remain active.

Update the server and reload browsers. Install the new installer on Remote Manager PCs for updated credential validation.
