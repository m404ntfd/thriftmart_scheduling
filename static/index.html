OneDrive backups & recovery

Save complete backups of appointments, vehicles, employee accounts and settings. Choose a OneDrive folder on the server computer.

Keeps the latest 90 complete backups. “Saved” means written to the local OneDrive folder; confirm OneDrive shows it synced. Backups contain customer information and accounts.

To recover on a replacement computer: install the Server, choose Exit server from its truck tray menu, then open Restore Thrift Mart Dispatch Server from the Start menu and select a synced backup ZIP. Sign in using an account from that backup, then reconnect the OneDrive folder.
